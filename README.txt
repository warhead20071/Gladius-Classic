This is a very early demo. I decided to release this version because I never planned on working on it again after porting it to gamemaker and I didn't want this to go to waste. I fixed a bunch of bugs and impleented a bunch of unfinished mechanics to put the game in a playable state. Gladius Classic will probably never get another update after this. If a bunch of people discover bugs that I never found then I'll fix them. The final game will probably be very different, but this will give you an idea of how the game is going to play. All the sprites are placeholders and there is no sound. As a thank you for taking the time to read this, I'll let you in on a secret. You can input the konami code anywhere to activate developer cheats. You can find them in the pause menu. Have fun.
